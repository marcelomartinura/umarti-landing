# Landing de consultoría · Umarti Digital

Sitio estático publicado en https://consultoria.umartidigital.com (Hostinger, despliegue desde GitHub).

- `index.html`: la página.
- `assets/css/styles.css`: estilos.
- `assets/img/`: logo y retrato.
- `contact.php`: envía el formulario por email. Cambiar `DESTINO` por la casilla que recibe los contactos.

Regla de contenido: no publicar nombres de clientes ni de partners.
